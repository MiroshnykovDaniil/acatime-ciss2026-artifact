# Component licenses

This repository contains several kinds of material with different licenses:

| Component | License |
|---|---|
| Source code in `code/` | Apache-2.0 (`LICENSE-APACHE`) |
| Data, logs, summaries and documentation | CC BY 4.0 (`LICENSE`) |
| Public ITC 2019 reduced datasets | The DTU dataset's own license; see `itc-data/README.md` |
| Third-party dependencies | Their respective licenses; see `THIRD_PARTY_NOTICES.md` |

The Apache-2.0 license applies to the code authored in this repository. It does
not relicense the DTU data or third-party components.

If you reuse the ITC data, cite the DTU dataset DOI in addition to this artifact.
